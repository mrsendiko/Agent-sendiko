Agent Memory

Sinkronkan catatan lintas perangkat dengan Supabase Cloud. Memory lokal tetap tersedia.

Cloud Memory

Masuk menggunakan akun Supabase Anda untuk menyimpan memory di cloud. Perlu konfigurasi Supabase sekali saja.

Cloud belum dikonfigurasi.
Petunjuk setup cloud

Di Supabase buat project, aktifkan Email Auth, lalu buat tabel memories dengan kolom id (uuid, default gen_random_uuid()), user_id (uuid), note (text), created_at (timestamptz, default now()). Aktifkan RLS dan policy SELECT/INSERT/UPDATE/DELETE agar user_id = auth.uid(). Gunakan URL dan anon/publishable key saja; jangan masukkan service_role key.

CATATAN TERSIMPAN

Memory lokal tetap tersimpan di perangkat. Cloud Memory aktif hanya setelah konfigurasi, login, dan sinkronisasi berhasil. Jangan simpan data rahasia atau sensitif.

Petunjuk deploy Netlify

Unggah ZIP proyek ini ke Netlify. Buka Site configuration → Environment variables, tambahkan API key provider yang dipilih, lalu deploy ulang. Jangan pernah menaruh API key di file website.

Catatan model lokal

Ollama atau model lokal berjalan di komputer milik pengguna. Website yang di-host di Netlify tidak dapat mengakses localhost milik HP secara langsung. Untuk menghubungkannya perlu tunnel aman atau backend yang berjalan di jaringan yang sama.
